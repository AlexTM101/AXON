# Использование AXON

## Запуск и подключение

Откройте `Axon.Desktop.exe` в распакованной папке приложения. Все соседние файлы нужны для работы. Устанавливать .NET отдельно не требуется.

Источник определяется в таком порядке: параметр запуска `--codex-home`, сохранённая папка, переменная `CODEX_HOME`, затем папка `.codex` в профиле пользователя. Выбрать папку вручную можно через «Подключение».

Новые агенты появляются после записи данных самим Codex. Метка подключения подтверждает доступность файлов, а не активность процесса Codex. Восстановление большой истории может занять время.

## Карта и панели

- Окно можно перемещать за верхнюю панель, включая логотип и подпись. Двойное нажатие на неё разворачивает или восстанавливает окно. Кнопки управления окном работают отдельно.
- Стрелка слева раскрывает список чатов. Панели можно сворачивать независимо.
- Нажатие на световую точку или имя открывает сведения об агенте.
- Перетаскивание свободного пространства перемещает карту; колесо меняет масштаб. `Home` показывает всю доступную карту.
- Нижняя лента открывает события, полный состав команды и опубликованный план. «События» слева открывают историю на всю центральную область.
- Выбор скрытого агента из списка раскрывает нужных родителей на карте. Другие свёрнутые ветви сохраняются.
- «Следовать за новым чатом» автоматически переключает наблюдение на последний обновлённый корневой чат. При выключенном переключателе выбранный чат сохраняется.
- «Уменьшить движение» останавливает декоративную анимацию и импульсы. Данные продолжают обновляться.

Состояние агента и свежесть записи показываются отдельно. Тишина в журнале не подтверждает завершение работы. Если структурированный план не записан, AXON не придумывает его.

## Локальные данные

Настройки и профиль WebView2 хранятся в локальной папке данных AXON пользователя. Сообщения, рассуждения, аргументы и содержимое результатов инструментов не включаются в отображаемое представление событий. Путь источника, имена чатов и метаданные агентов используются локально.

Не добавляйте в репозиторий реальные журналы, настройки, профили, снимки своей переписки или диагностические файлы. Для отчёта об ошибке используйте искусственный пример.

## Параметры запуска

```text
--codex-home <directory>   Явно выбрать источник
--data-dir <directory>     Использовать отдельный профиль AXON
--smoke-test               Проверить запуск и завершить приложение
--screenshot <file.png>    Сохранить проверочный снимок
```

Последние два параметра предназначены для локальной разработки. Созданные ими файлы не следует включать в репозиторий или распространяемый архив.

## Ограничения

AXON зависит от доступных локальных журналов и поддерживаемых форматов записей Codex. Недостающие или удалённые данные восстановить невозможно. При недоступной ускоренной графике используется упрощённая сцена Canvas2D.
