# AXON

Локальная обсерватория Codex для Windows 11 x64. Показывает агентов и субагентов, их связи, записанные события и опубликованный план в виде анимированной нейросети.

AXON помогает следить за большой задачей: видеть, какие агенты работают параллельно, кто кому делегировал работу, где появились новые события и какие этапы уже завершены. Вместо просмотра нескольких журналов можно наблюдать общую картину на одной карте и открывать подробности выбранного агента.

AXON предназначен для наблюдения. Он читает локальные журналы Codex и не запускает задачи, не меняет настройки Codex и не требует ключа API или отдельного сервера.

## Скачать и запустить

Готовая сборка доступна в [релизах](https://github.com/AlexTM101/AXON/releases/latest). Скачайте `AXON-Win11-public.zip`, распакуйте архив целиком и откройте `AXON/Axon.Desktop.exe`.

Нужны Windows 11 x64 и Microsoft Edge WebView2 Runtime. Среда .NET уже включена; Node.js и средства разработки для запуска не требуются. Источник Codex определяется автоматически, другую папку можно выбрать через «Подключение».

`AXON-git.zip` содержит подготовленные исходники. Для обычного использования достаточно Windows-сборки.

## Возможности

- Анимированная карта агентов и субагентов с устойчивым расположением узлов и связями между ними.
- Выбор чата вручную или автоматическое наблюдение за последним обновлённым чатом.
- Сведения о выбранном агенте, история событий, список команды и записанный план.
- Сворачиваемые панели, масштабирование и перемещение карты.
- Режим уменьшенного движения и запасная графика Canvas2D при недоступном ускорении.
- Локальное чтение данных: без отправки журналов на сервер и без ключей API.

## Сборка

Нужны Windows 11 x64, PowerShell и .NET SDK 10.0.100 или новее в ветке 10. При первом восстановлении зависимостей требуется доступ к NuGet.

```powershell
./build.ps1
```

Результат — папка `dist/AXON`. Переносите её целиком: среда .NET включена в сборку. Для запуска интерфейса нужен Microsoft Edge WebView2 Runtime, обычно установленный в Windows. При его отсутствии приложение предлагает официальную страницу установки.

## Проверки

Для проверок геометрии дополнительно нужен Node.js 24 или новее.

```powershell
./scripts/test.ps1
```

Проверка графики в Google Chrome включается отдельно:

```powershell
./scripts/test.ps1 -Browser
```

Путь к Chrome при необходимости задаётся переменной `CHROME_PATH`. Все тестовые данные создаются искусственно; рабочая история Codex для тестов не требуется.

## Использование

Откройте `Axon.Desktop.exe`. Приложение автоматически ищет папку Codex. Другой источник выбирается через «Подключение». Подробности управления — в [руководстве](docs/USAGE.md).

Светящиеся нити показывают подтверждённые связи агентов. Импульсы соответствуют новым записанным событиям. Движение ядра — оформление; оно не отображает внутреннее мышление модели.

## Структура

- `src/Axon.Core` — чтение журналов и безопасное представление событий.
- `src/Axon.Desktop` — окно Windows и локальный интерфейс WebView2.
- `tests` — проверки наблюдателя, настроек и графики.
- `scripts` — запуск проверок.
- `licenses` — лицензии сторонних зависимостей.

Служебные папки сборки и локальные данные исключены через `.gitignore`. В репозиторий не нужно добавлять папку Codex, настройки приложения или профили WebView2. Готовую папку `dist/AXON` можно распространять отдельно как архив для релиза.
